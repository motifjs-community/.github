# motifjs-community/.github

Organization-wide files for [motifjs-community](https://github.com/motifjs-community).

- `profile/README.md`: the organization profile page
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`: defaults for every repository without its own
- `.github/ISSUE_TEMPLATE/`, `.github/PULL_REQUEST_TEMPLATE.md`: default issue and pull request templates

GitHub uses these files for any repository in the organization that does not have its own copy.
