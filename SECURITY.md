# Security policy

Please do not report security problems in public issues.

Open a private report through the **Security** tab of the affected repository ("Report a vulnerability").
If the problem is in `@motifx/core` or `@motifx/compiler`, report it in
[motifjsdev/motifjs](https://github.com/motifjsdev/motifjs/security/advisories/new) instead.

Include the package and version, a description of the problem and, if possible, a minimal reproduction.
We aim to answer within a week. Fixes are released for the latest minor version.
